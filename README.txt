DIWALI MOVIE-STYLE GREETING WEBSITE
===================================

Files:
- index.html
- style.css
- script.js
- assets/diwali-background.png

Features:
- Cinematic Diwali background artwork
- Sender and receiver name fields
- Manual custom greeting message
- Family/friends list: write one person per line, e.g. "Mummy - ...", "Papa - ..."
- Live date and time
- Fireworks animation
- Optional locally generated instrumental-style melody (no voice)
- WhatsApp share button

HOW TO PUBLISH ON GITHUB PAGES
1. Extract this ZIP on your phone/computer.
2. Upload all files and the assets folder into the repository root. Do not upload only the ZIP.
3. Make sure index.html, style.css, script.js and assets/diwali-background.png are in the correct locations.
4. GitHub repository -> Settings -> Pages.
5. Select "Deploy from a branch", branch "main", folder "/ (root)", then Save.
6. Open the Pages URL GitHub provides.

Tip: In the website tap "अपना मैसेज लिखें". Enter a custom greeting, then put family members one per line in the family box. Format: Name - personal wish.
